丹丹大冒险 · 世界 1-1
====================

怎么玩：双击 index.html（浏览器直接打开，断网也能玩）。
手机：横过来，左下 ◀ ▶ 走，右下「跳」。竖屏会提示转屏。

操作
----
移动：← → 或 A D
跳跃：空格 / ↑ / W / K（按住跳得高，轻点是小跳）
重开：通关或结束后按 R

规则（照原版超级玛丽）
--------------------
· 踩怪：从上方踩下去能踩扁；红色的尖刺球踩不得，只能躲
· 顶砖：跳起来顶砖块，砖会碎，问号砖出金币
· 金币：直接吃到也算，一个 200 分
· 碰到怪不是直接死：扣一格血 + 被你弹开 + 1.6 秒无敌闪烁（角色会闪）
· 血一共 3 格，扣光才掉一条命、从最近的路标重来；掉坑仍然直接掉命
· 右上角 生命 ♥♥♥ = 当前血，×3 = 还剩几条命
· 三格宽以上的坑要助跑起跳
· 时间 400，走完旗杆结算，剩余时间按 10 分/秒折算

关卡结构（252 格，约 10000 像素）
--------------------------------
① 起步区：问号砖、第一只怪
② 砖块区：连排砖 + 金币
③ 水管区：三根高低不同的水管
④ 深坑区：两处三格坑 + 浮台 + 尖刺球
⑤ 楼梯区：上下金字塔
⑥ 空中平台：三层跳台 + 金币串
⑦ 砖块迷宫
⑧ 石柱区：两根柱子
⑨ 冲刺段 → 旗杆

素材
----
主角：用你给的丹丹像素图集。原图集里侧身帧朝向不统一（side0 朝右、side1/side2 朝左），
      已把后两帧镜像统一成朝右，另存为 assets/girl_face-right.webp（原始 girl.webp 没动，序章还在用）。
      走路用 side1/side2 左右脚交替两帧，朝左时整体镜像。
地形与怪物：全部程序生成（assets/sheet.webp，852 字节）
背景：天空渐变 + 视差云 / 山 / 草丛，全部 canvas 画，不加载外部图

自检参数（正式玩不用管）
----------------------
?sim=帧数&bot=1   同步跑 N 帧并让机器人试玩（无头验收用）
?x=格号           从指定格出生
?dbg=1            打印机器人决策

手感调参（改 game.js 顶部这几行，其它地方不用动）
--------------------------------------------
JUMP  = -1120   跳多高（越负跳越高）
GRAV  =  2700   落多重（越大下落越快、滞空越短）
RUN   =   300   跑多快
STOMP =  -720   踩到怪之后的反弹高度

当前实测净跳跃高度：223px ≈ 5.6 格
关卡高度基准：砖块顶面 4 格（160px）、最高台阶 4 格、石柱最高 3 格
所以现在站在地上就能直接跳上砖块，余量约 1.5 格

终点演出
--------
碰到旗杆后不是直接结算，走这段：
1. 丹丹抓着旗杆滑下来，挂在杆顶的噜噜同时滑下来（原版马里奥的滑杆）
2. 镜头往右推，露出站在旗子后面的松松
3. 两句台词：这是……噜噜 ／ 丹丹说过这是她最喜欢的角色
6. 噜噜在还没触杆时就已经挂在杆顶了（不是碰了才出现）
4. 那张聊天截图像「他掏出手机给你看」一样，从左侧滑进来（白边框 + 投影 + 轻微倾斜）
5. 点一下继续 → 不再弹结算，直接恢复操控

素材
----

assets/chat.webp  微信截图裁成的卡片图
assets/boy.webp   松松（从 memory-trip 拿的，终点用正面帧，不涉及左右镜像）
通关之后
--------
· 卡片看完后点一下屏幕，人物恢复可操控（时间和怪都停/清空了）
· 右边有一个管道，上方有浮动的黄箭头指着它
· 松松会自己走过去钻进管道
· 你自己跳上管口站定，就会自动沉下去 → 渐隐 → 黑屏 → 第二关
· 第二关还没做，黑屏上先写着「第二关 / 敬请期待」，按 R 可以重玩本关
· 管道右边堵了一堵砖墙：不然玩家能直接跳过管子绕到关卡尽头（实测机器人就会这么干）


第二关（和平精英式肉鸽）
========================
从第一关的管道黑屏后自动进入；也可以直接打开 index.html?s2=battle 单独看。

流程：登场特效 → 选你的枪（P90/GROZA/AUG/98K 四格）
      → 选松松的枪（四格全是 98K）→ 清 8 只怪 → 大吉大利今晚吃鸡
      → 点屏幕，空投箱从天而降掉在地图上（在你旁边）
      → 走过去碰到它：箱子弹一下，聊天记录从箱子里弹出来
      → 卡片停 2.6 秒自动接成就「故事的开始」（点一下也能提前）
      → 成就停 3 秒后自己缩回去，卡片同时缩走
      → 箱子旁边生成一个漩涡传送门，走进去 → 黑屏 → 第三关

第三关还没做，黑屏上先写着「第三关 / 敬请期待」。

操作：按住左半屏拖动 = 轮盘移动（8 方向）；键盘 WASD / 方向键也行
攻击：全自动，自动瞄最近的怪，玩家只管走位

数值（对标和平精英手感，做了平衡）
--------------------------------
P90     35 伤 / 0.067 秒一发 / 弹匣 50 / 换弹 2.4 秒
GROZA   47 伤 / 0.086 秒一发 / 弹匣 30 / 换弹 2.6 秒
AUG     43 伤 / 0.086 秒一发 / 弹匣 30 / 换弹 2.6 秒
98K     79 伤 / 1.5 秒一发   / 弹匣 5  / 换弹 3.0 秒
怪物    2400 血（P90 扫射约 5 秒一只），移速 38~52，同时只出 1 只，
        死一只等 1.3 秒补下一只，4 种皮肤各出现两次 = 共 8 只
实测时长约 55 秒（目标是 1 分钟）

第三关（拼图）
==============
从第二关传送门黑屏后进入；也可以直接打开 index.html?s3=play 单独看。

流程：
1. 黑底中间是一块白色空缺区（3 列 x 2 行），四周散落 6 块碎片（带角度，像随手放着）
     · 玩法：按住碎片拖进中间对应的格子，松手时离目标格中心 78px 内自动吸附
     · 拖错了会弹回原位；顶部显示「还差 N 块」
2. 丹丹在左半边、松松在右半边，各自来回走（中间过不去）
3. 6 块全部归位 → 两人刹车停住，松松头顶弹出「!」气泡，同时解锁跨区
4. 按左右键（或点屏幕左/右半边）操控丹丹跨过半屏走向松松
5. 碰到后拼图让位，聊天记录「拼好了 / 你的」放大浮现
6. 左下弹出成就「你的礼物我很喜欢」
7. 点一下 → 黑屏 → 待续

素材：assets/puzzle.webp（459x560，裁掉编号）、assets/chat3.webp（677x620）


第三关之后：米线店 → 海边
==========================
从第三关拼图结束的黑屏后进入；也能直接打开 index.html?s4=shopTalk 看。

场一 米线店门口
  · 松松：我记忆里你喜欢吃米线吧 / 能陪我一起吃碗米线吗 / 再陪我聊聊
  · 说完松松自己走进店里（渐隐），然后玩家操控丹丹走进店门（也渐隐）→ 黑屏

场二 海边日落
  · 操控角色换成松松；松松在最左，丹丹在中间，丹丹头顶一个「!」
  · 按左右（或点半屏）操控松松走近她 → 触发 6 句告白
  · 说完只给一个选项「好」，点它进入回忆段
  · 回忆段：视频竖屏铺在中间，两人被挤到画面两侧；右上角时钟狂转，
    左上角日历从 8 月 29 日一路撕到 11 月 27 日，撕下来的纸片飘落渐隐
  · 播完 →「11 月 27 日 / 故事还长」
